Reset CPU Module power cycles the CPU Module.

When Reset CPU Module is selected, devices connected to the 8810 RTU lose communication, including the device that initiated the reset. Communication is restored once the firmware re-initializes the RTU which should take approximately 1 minute.

NOTE: An external USB flash drive cannot be inserted when performing this option.

Apply New Firmware allows the user to upgrade the CPU Module’s firmware through the use of an external USB flash drive.

The user must copy the desired firmware files onto a USB flash drive and then plug it into one of the two USB slots on the CPU Module’s front panel. A 3 second message will display on the LCD explaining the CPU has detected an external USB flash drive is connected.

Once the USB flash drive is connected, click Apply Firmware to start the process. It will take approximately 60 seconds to copy the firmware to the CPU.

Apply New Database to RTU allows the user to restore an RTU’s database from an external USB flash drive.

NOTE: The user must perform the “Backup Database to USB Drive” system command before performing this command.

The user must plug in an external USB flash drive containing a database into one of the two USB slots on the front plate of the CPU Module.

Once the USB flash drive is connected, click Apply New DB to start the process. This process can take up to 60 seconds to complete.

To complete the process, the USB flash drive will need to be removed for the RTU to power cycle and start using the new database.

Command Status : {{getCommandStatusMsg()}}

Backup Database to USB Drive allows the user to create a backup copy of the current 8810 RTU database.

The user must plug in an external USB flash drive into one of the two USB slots on the front plate of the CPU Module to begin the backing up process.

Once the USB flash drive is connected, click Backup DB to start the process. This process can take approximately 3 minutes to complete.

Factory Reset allows the user to restore the RTU’s entire configuration database to its factory default settings. This resets every setting except for SystemTime since that information is stored on the battery backed-up Real-Time Clock.

CAUTION: All settings as stated above will be lost except SystemTime. This includes the IpAddress being defaulted and the TCP/IP device will be unable to communicate with the RTU once the process completes.

Command Status : {{getCommandStatusMsg()}}

Factory Reset Limited allows the user to restore the RTU’s configuration to factory default settings with the exception of IpAddress, SubnetMask, Gateway, and SystemTime. This allows the RTU to remain connected to the TCP/IP device after the reset completes.

Command Status : {{getCommandStatusMsg()}}

Password Reset restores through the use of an external USB drive the admin and user1 usernames and passwords to their default values. This process also restores all the security settings on the 8810 RTU to their default values where Security Mode is set to None, Security Policy is set to None, and the User Identity is set to Username.
